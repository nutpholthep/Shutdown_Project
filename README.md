## 1. ภาพรวมโปรแกรม

**Shutdown Scheduler v3.0** เป็นโปรแกรมตั้งเวลาปิดเครื่องคอมพิวเตอร์อัตโนมัติ 
ออกแบบด้วยดีไซน์ **Cute & Modern Dark Velvet Pastel** (Soft Lavender, Sakura Pink & Mint Glow) สวยงาม น่ารัก ใช้งานง่าย และรองรับการทำงานเบื้องหลังในระบบถาดซ่อน (System Tray / "Show hidden icons") ของ Windows

### ✨ คุณสมบัติหลัก v3.0

| คุณสมบัติ | รายละเอียด |
|---|---|
| ⏱ **โหมดนับถอยหลัง (Timer Mode)** | เลือกตั้งเวลาถอยหลัง (ชั่วโมง/นาที/วินาที) หรือใช้ปุ่ม Quick Presets (15น., 30น., 1ชม., 2ชม.) |
| ⏰ **โหมดตั้งเวลาเฉพาะ (Schedule Clock)** | กำหนดเวลาปิดเครื่องตามเวลาในนาฬิกา เช่น `23:30 น.` (รองรับโหมดซ้ำทุกวัน Daily) |
| 🌸 **การทำงานเบื้องหลัง (System Tray)** | ย่อเก็บหน้าต่างลงถาดซ่อน "Show hidden icons" บน Windows เมื่อปิดหรือย่อหน้าต่าง |
| 🎀 **Cute Modern Aesthetic** | ธีมพาสเทลน่ารัก ปุ่มโค้งมน (Pills) การ์ดนุ่มนวล และดวงดาวสัญลักษณ์น่ารัก |
| ⚠️ **แจ้งเตือนก่อนปิด 5 นาที** | ป๊อปอัปแจ้งเตือนก่อนปิดเครื่อง 5 นาที ล่วงหน้า พร้อมปุ่มยกเลิก |
| 🛑 **ควบคุมง่ายผ่าน System Tray** | คลิกขวาที่ไอคอนถาดระบบเพื่อดูเวลาคงเหลือ, เปิดหน้าต่างหลัก, หรือยกเลิก |
| 💻 **รองรับหลาย OS** | Windows, macOS, Linux |

```powershell

```

### ขั้นตอนที่ 3: รันโปรแกรม

```powershell
python shutdown_scheduler.py
```

## 4. การ Build เป็นไฟล์ .exe

หากต้องการสร้างไฟล์ `.exe` สำหรับรันบน Windows โดยไม่ต้องมี Python:

```powershell
cd C:\Work\Shutdown_Project
python -m PyInstaller ShutdownScheduler.spec --clean
```

ไฟล์ `.exe` ที่ได้จะถูกสร้างไว้ในโฟลเดอร์ `dist/ShutdownScheduler.exe`

## 5. วิธีใช้งานโปรแกรม

### ⏱️ 1. โหมดนับถอยหลัง (Timer Tab)
1. เลือกจำนวน **ชั่วโมง / นาที / วินาที** ด้วยปุ่ม `▲` / `▼`
2. หรือกดเลือกปุ่ม Quick Preset เช่น `⚡ 30 นาที`
3. กดปุ่ม `▶ เริ่มนับถอยหลัง`
4. หากต้องการยกเลิก ให้กด `✕ ยกเลิก`

### ⏰ 2. โหมดตั้งเวลาเฉพาะ (Schedule Tab)
1. เลือกเวลาเป้าหมายที่ต้องการให้ปิดเครื่อง (เช่น `23` ชั่วโมง `30` นาที)
2. ติตติ๊กถูกที่ `🔁 ทำงานซ้ำทุกวัน (Daily Schedule)` หากต้องการให้ระบบตั้งเวลาในวันถัดไปอัตโนมัติ
3. กดปุ่ม `⏰ ตั้งเวลาปิดเครื่อง`

## 6. การตั้งค่า System Tray (ทำงานเบื้องหลัง)

- **การย่อเก็บลง System Tray**: 
  - เมื่อเปิดสวิตช์ `📌 ย่อลง System Tray เมื่อกดปิดหน้าต่าง (X)` ในหน้าตั้งค่า
  - เมื่อกดปุ่มปิด (`X`) หน้าต่างจะซ่อนไปรันเบื้องหลังตรงมุมขวาล่าง "Show hidden icons"
- **การควบคุมผ่านเมนูคลิกขวาที่ถาดระบบ (Tray Icon)**:
  - 🌸 **เปิดหน้าต่างหลัก**: ดึงหน้าต่างแอปกลับขึ้นมาด้านหน้า
  - ⏱️ **เวลาคงเหลือ**: แสดงเวลาคงเหลือในการปิดเครื่อง
  - 🛑 **ยกเลิกการปิดเครื่อง**: หยุดการนับถอยหลังทันที
  - ❌ **ออกจากโปรแกรม**: ปิดแอปพลิเคชันอย่างสมบูรณ์

## 1. ภาพรวมโปรแกรม

**Shutdown Scheduler v4.1** เป็นโปรแกรมอรรถประโยชน์ (Utility Application) สำหรับตั้งเวลาปิดเครื่องคอมพิวเตอร์อัตโนมัติบนระบบปฏิบัติการ Windows ออกแบบตามมาตรฐาน **Windows 11 Fluent Design System (WinUI 3)** เน้นความเรียบหรู คมชัด สบายตา ไม่รกรุงรัง และมีความเป็นมืออาชีพ

### คุณสมบัติเด่นใน v4.1

| คุณสมบัติ | รายละเอียด |
|---|---|
| 🎨 **Windows 11 Fluent Design** | ธีม Dark Mode มาตรฐาน WinUI 3 โทนสี Mica (`#202020`), Layer Card (`#2b2b2b`) และ Accent Blue (`#0078d4`) |
| 🪟 **Native DWM Integration** | ผสานกับ Desktop Window Manager ของ Windows 11 โดยตรงเพื่อ Title Bar สีเข้มและขอบหน้าต่างมนตามระบบ |
| 🌐 **Bilingual System (TH / EN)** | สลับภาษาไทยและอังกฤษได้ทันที คำแปลเป็นทางการตามมาตรฐาน Microsoft Windows |
| ⏱ **โหมดนับถอยหลัง (Timer)** | กำหนดชั่วโมง นาที วินาที หรือเลือก Quick Presets ด่วน (15 นาที, 30 นาที, 1 ชม., 2 ชม.) |
| 📅 **โหมดตั้งเวลาตามนาฬิกา (Schedule)** | ระบุเวลาเป้าหมาย (เช่น `23:30`) รองรับการสั่งปิดเครื่องซ้ำทุกวัน (Daily Repeat) |
| 🔔 **แจ้งเตือนล่วงหน้า 5 นาที** | หน้าต่างแจ้งเตือนสไตล์ Windows 11 ก่อนปิดเครื่อง 5 นาที พร้อมปุ่มยกเลิกได้ทันที |
| 📌 **System Tray Background** | ย่อทำงานเบื้องหลังใน System Tray ไม่เกะกะแถบงาน พร้อมเมนูคลิกขวาควบคุมครบวงจร |

## 5. วิธีใช้งานโปรแกรม

### 5.1 โหมดตัวนับเวลาถอยหลัง (Countdown Timer)
1. เลือกเมนู **ตัวนับเวลา (Timer)** ทางแถบซ้าย
2. ปรับตัวเลข ชั่วโมง นาที หรือวินาที ผ่านปุ่ม `▲` / `▼` หรือกดปุ่มช็อตคัต (15 นาที, 30 นาที, 1 ชม., 2 ชม.)
3. กดปุ่มสีน้ำเงิน **เริ่มนับถอยหลัง**
4. หน้าจอจะแสดงตัวเลขนับถอยหลังแบบเรียลไทม์ และปุ่มยกเลิกจะเปิดให้ใช้งาน

### 5.2 โหมดกำหนดเวลาปิดเครื่อง (Clock Schedule)
1. เลือกเมนู **กำหนดเวลา (Schedule)** ทางแถบซ้าย
2. ระบุเวลาเป้าหมาย (24 ชั่วโมง เช่น 02:00)
3. เปิดสวิตช์ **ทำงานซ้ำทุกวัน** หากต้องการให้ระบบปิดเวลานี้ทุกวัน
4. กดปุ่ม **กำหนดเวลาปิดเครื่อง**

### 5.3 การตั้งค่าระบบ (Settings)
- **ย่อลง System Tray เมื่อปิดหน้าต่าง**: เมื่อปิดหน้าต่าง (X) โปรแกรมจะไปทำงานเบื้องหลังแทนการปิด
- **แจ้งเตือนก่อนปิดเครื่อง 5 นาที**: แสดงหน้าต่างเตือนก่อนเวลาปิด 5 นาทีเพื่อป้องกันงานสูญหาย

## 6. การทำงานในถาดระบบ (System Tray)

เมื่อย่อหรือปิดหน้าต่าง:
- ไอคอนวงแหวนสีฟ้า Fluent จะปรากฏใน **"Show hidden icons"** (มุมขวาล่างของ Taskbar)
- **ดับเบิลคลิกที่ไอคอน**: เปิดหน้าต่างหลัก
- **คลิกขวาที่ไอคอน**:
  - `เปิด Shutdown Scheduler`: แสดงหน้าต่างหลัก
  - `เวลาคงเหลือ`: แสดงข้อความ Notification แจ้งเวลาที่เหลือก่อนปิดเครื่อง
  - `ยกเลิกการปิดเครื่อง`: ยกเลิกคำสั่งปิดเครื่องทันที
  - `ออกจากโปรแกรม`: ยกเลิกและปิดแอปอย่างสมบูรณ์
